Actual data layer

Official Afghanistan indicators.

Latest non-null national values from the World Bank WDI API. These are suitable for proposal context, country profiles, and dashboard baselines; province layers require separate official or clearly modelled datasets.

Official baselineNational values are pulled from public source APIs and shown with year, unit and source link.

Usability rules
One clickEvery launch card opens the app, repository or build plan directly.
One mapProvince boundaries, scores and next-build ideas live in the same map section.
One source trailEvery data layer must have a source file, source URL and method note.
Local accessMap instructions support English, Afghanistan Dari and Pashto.
